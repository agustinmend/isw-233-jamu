# Bloques identificados
## Encabezado
Parte superior de la pagina con los diferentes que contiene los titulos que direccionan a distintas partes de la pagina
## Principal
Inicio de la pagina que contiene el titulo principal carrera/profesion y el nombre del dueño del portefolio
## Sobre mi
Bloque en el que se presenta el dueño de el portafolio, incluye elementos como imagen, titulo, saludo y un texto de presentacion
## Habilidades
Donde se muestran las habilidades tecnicas en diversas areas que tiene el dueño, este bloque se separa en 3 segmentos con el mismo estilo, conteniendo iconos, titulos, listas
## Proyectos
Se muestra un poco los trabajos realizado por el dueño mostrando su experiencia, este bloque reutiliza estilos para sus elementos
## Blog
El bloque Blog contiene elementos como publicaciones que cuentan con su css y atributos respectivos
## Contacto
En Contacto encontramos diversos elementos algunos que reutilizan css como ser los inputs y textos, este tambien contiene al boton Enviar
## PieDePag
Al final de toda la pag se encuentra este bloque que contiene las redes sociales, como el derecho de autor
